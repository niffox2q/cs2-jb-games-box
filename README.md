## Описание

Добавляет игровой режим «Бокс» в Jailbreak.  
Начальник тюрьмы может включать и выключать режим, который активирует дружеский огонь между заключёнными (все против всех внутри террористов).

При повторном использовании функция отключается, возвращая стандартное поведение сервера.  
Также состояние автоматически сбрасывается в начале нового раунда.
